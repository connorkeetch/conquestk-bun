# Beta Tester Onboarding & Expectations

_Last updated: October 8, 2025_

Welcome to the ConquestK beta! This private friends-only soft launch is focused on validating the ranked experience, notifications, and honest UI before we invite a wider audience. Please read through the following guidance so you know what to expect and how to share feedback.

## 1. Scope & Goals
- **Audience:** 10–12 trusted friends helping us shake out launch blockers.
- **Primary goals:**
  - Complete ranked matches end-to-end and confirm CP awards are accurate.
  - Exercise the notification flow (PWA push or Discord/Slack relay).
  - Surface any confusing UX or messaging issues so we can prioritize fixes.
- **Out-of-scope for beta:** AI opponents, long-term plans/strategies tooling, and experimental game modes that are not explicitly called out below.

## 2. Before You Play
1. **Create or confirm your ConquestK account.** If you need an invite or account reset, ping Connor directly.
2. **Pick a notification path:**
   - _Preferred:_ Install the ConquestK PWA when prompted (desktop or mobile) and allow notifications.
   - _Fallback:_ Join the private Discord/Slack channel (details provided in your invite) to receive automated turn and game-completion summaries.
3. **Review the quickstart:** Skim the in-app tutorial or the "How to Play" section in the lobby so you understand the conquest ruleset.
4. **Coordinate a test session:** Pair up with at least one other tester to ensure we can validate ranked match completion.

## 3. Known Limitations (Please Expect These)
- AI opponents remain disabled; all matches require human players.
- Plans/strategies UI is labeled "Coming Soon" and should be ignored for now.
- Messaging: in-room chat is solid, but the global inbox dropdown is being actively tuned. If you notice unread badges sticking, capture a screenshot and note the steps.
- Only the listed game modes have been smoke-tested. If you stray into other combinations, let us know how it goes!

## 4. Test Checklist
- [ ] Install the PWA **or** join the Discord/Slack relay channel.
- [ ] Play at least one ranked match to completion with another human player.
- [ ] Confirm the post-game summary shows CP changes that match expectations.
- [ ] Send and read a direct message via the inbox dropdown; note any unread badge issues.
- [ ] Explore the map browser and favorite at least one community map.
- [ ] Optional: try one alternate mode from the supported list below.

### Supported Modes for Beta Smoke Tests
- Classic Conquest (default settings)
- Capitals mode
- Teams (2v2)
- Fog of War enabled

If you encounter errors in these modes, file them immediately so we can triage before inviting additional testers.

## 5. Reporting Bugs & Sharing Feedback
- **Preferred channel:** Reply in the beta Discord/Slack thread with a short description, screenshot, and time of occurrence.
- **Email fallback:** Send details to `beta@conquestk.com` if chat is unavailable.
- **Logs & repro steps:** Include browser (with version), device, and a quick checklist of what you were doing.
- Connor will track blocker status in the `docs/planning/go-live-plan.md`. Check there for updates before retesting a known issue.

## 6. Staying in the Loop
- We will post daily status updates and blocker summaries in the same Discord/Slack channel.
- Significant fixes or action items will also be documented in the go-live plan so you can see what changed between sessions.
- When the beta wraps, expect a short survey covering gameplay, notifications, and anything that surprised you.

Thank you for helping us harden ConquestK! Your honest feedback is the fastest path to a smooth public launch.
